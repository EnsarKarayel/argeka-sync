Installation review checklist

The setup process should be reviewed like any other self-hosted business application. After the installer finishes, confirm that Docker services are running, the panel opens in the browser, the API responds, the local database is available and the first login works. If the installation required a Windows restart during Docker or WSL preparation, run the installer again after reboot.

For a company environment, a controlled Windows server is usually better than a personal laptop. That makes backup, firewall rules, user access and restart procedures easier to manage. The installer is designed to help non-specialist users, but production use should still be validated by someone who understands database access and local service operation.

Download safety

The download page does not trigger automatic downloads. Users choose the setup file themselves. This gives visitors a clear product context before receiving an executable file and avoids presenting the website as a thin download-only page.
