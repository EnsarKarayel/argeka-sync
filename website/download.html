Self-hosted Windows setup

ARGEKA Sync'i kendi bilgisayarınıza kurun.

Kurulum dosyası uygulamayı yerel ortamda çalıştırmak için hazırlanmıştır. Panel varsayılan olarak bilgisayarınızda açılır; veritabanı bağlantıları, sorgular ve çalışma kayıtları sizin ortamınızda tutulur.

Windows setup indir CMD yedek kurulum

Bu sayfa otomatik indirme başlatmaz. Dosya yalnızca indirme butonuna bastığınızda iner.

Kurulumda neler hazırlanır?

Setup dosyası Git, Docker Desktop ve WSL durumunu kontrol eder; ARGEKA Sync servislerini başlatır ve masaüstüne uygulama kısayolu ekler. Kurulumdan sonra ürün bir internet sitesine değil, sizin yerel panelinize yönlenir.

Kurumsal kullanım için kişisel bilgisayar yerine yedekleme ve erişim kuralları belli olan bir Windows sunucu tercih edilebilir.

Bileşenler

  • ARGEKA Sync web paneli
  • API servisi
  • Yerel PostgreSQL veritabanı
  • Docker servisleri
  • Masaüstü çalıştırıcı

Hiç teknik olmayan kullanıcı için

Kurulumdan önce kısa kontrol listesi

  1. Windows bilgisayarda yönetici yetkisi gerekip gerekmediğini kontrol edin.
  2. Docker Desktop yüklü değilse kurulum sizi yönlendirebilir.
  3. WSL kurulumu gerekiyorsa Windows yeniden başlatma isteyebilir.
  4. Kurulum bittikten sonra masaüstündeki ARGEKA Sync kısayolunu kullanın.
  5. Canlı ERP verisine bağlanmadan önce test verisiyle deneme aktarımı yapın.
  6. Veritabanı bağlantısı için mümkünse sadece gerekli tablo veya view'ları okuyan teknik kullanıcı kullanın.
