ARGEKA Sync kurulumu

Setup dosyasi uygulamayi sizin bilgisayarinizda veya Windows sunucunuzda calistirmak icin hazirlanmistir. Kurulum sonrasinda panel varsayilan olarak localhost uzerinden acilir; veritabani baglantilari ve aktarim kayitlari sizin ortaminizda kalir.

Windows Setup

Onerilen kurulum dosyasi ARGEKA-Sync-Setup.exe dosyasidir. Dosya Git, Docker Desktop ve WSL durumunu kontrol eder, gerekli servisleri hazirlar ve masaustune ARGEKA Sync kisayolu ekler.

Kurulumdan once kontrol listesi

  1. Windows kullanici yetkisinin kurulum icin yeterli oldugunu kontrol edin.
  2. Docker Desktop kurulu degilse setup sizi yonlendirir.
  3. WSL kurulumu sonrasi Windows yeniden baslatma gerekebilir.
  4. Kurulum bittiginde tarayicida http://localhost:8080 adresi acilir.
  5. Canli kullanimdan once demo sifresini degistirin.
  6. ERP veritabanina baglanmadan once yalnizca okuma yetkili teknik kullanici tercih edin.

Indirme sayfasinin amaci

Kurulum sonrasi ilk kontrol

Kurulum tamamlandiginda ilk is panelin acildigini gormek degil, servislerin karisik olmayan bir durumda calistigini dogrulamaktir. Tarayicida panel acildiktan sonra API sagligi, veritabani baglantisi, demo kullanici girisi ve Docker container durumlari kontrol edilmelidir. Eger Windows yeniden baslatma istedi ise setup dosyasi ikinci kez calistirilmalidir; bu durum WSL veya Docker kurulumu tamamlanirken normaldir.

ARGEKA Sync self-hosted calistigi icin kurulum yapan kisi bilgisayarin firewall, port, VPN ve veritabani erisim politikasini bilmelidir. Kurumsal ortamda uygulama bireysel bilgisayar yerine ekip tarafindan erisilen kontrollu bir Windows sunucuda calistirilabilir. Bu durumda yedekleme ve sifre yonetimi daha duzenli hale gelir.
